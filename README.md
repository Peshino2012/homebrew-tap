# homebrew-tap

Homebrew tap for tools published from [Peshino2012/PD1](https://github.com/Peshino2012/PD1).

## Usage

```
brew install peshino2012/tap/agents-md-gen
```

## Available formulae

- **agents-md-gen** — generate a solid AGENTS.md/CLAUDE.md for any repo by
  detecting its stack, commands, and structure.
  ([npm](https://www.npmjs.com/package/agents-md-gen))
